# ふたりの作業ボード

2人の開発者で小さなタスクを分け合うための、シンプルなボードです。HTML・CSS・JavaScriptだけで動き、追加のインストールはありません。

## 使い方

1. このリポジトリを clone します。
2. `index.html` をブラウザーで開きます。
3. タスクを追加し、担当と進み具合を選びます。

開発中はリポジトリのフォルダーで `python -m http.server 8000` を実行し、`http://localhost:8000` を開く方法も使えます。

## 2人でGitHubを使う

- 変更ごとに `feature/短い説明` のようなブランチを作り、`main` に直接コミットしない。
- 作業を終えたらPull Requestを作り、もう1人が差分を確認してから取り込む。
- 最初の作業は、ひとりが画面の見た目、もうひとりがタスクの操作や説明文を担当すると分けやすいです。
- 共通の作業項目はGitHub Issuesに書き、担当者を決めてから着手します。

詳しくは [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。

## 保存について

タスクは開いたブラウザーのローカルストレージに保存されます。別の人のパソコンや別のブラウザーとは同期されません。このリポジトリで共有するのはアプリのソースコードです。タスクデータのオンライン共有が必要になったら、保存先やログイン方法を決めてから追加してください。

## 現在の機能

- タスクの追加、編集、削除
- 「これから」「進行中」「完了」の移動
- 開発者 A / B の担当割り当て
- タイトル・メモの検索と担当者での絞り込み
- 同じブラウザーの別タブとの変更反映
